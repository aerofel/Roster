# Project Memory

- **Scheduled vs actual times (2026-09-28)**: verified on the live Alexis feed — it carries ONE set of times: schedule (round 5-min values, = flight-plan STD) until flown, then Departure/Arrival are OVERWRITTEN with actual block times (minute-precise), Checkout = Arrival + 0:30, **Checkin never updated** (= STD − 1:30 on long-haul, so checkin + learned offset recovers STD). **TFT = Checkin → Arrival, NOT block** (user: "only scheduled times and actuals" — TFT is never exported). No SEQUENCE/LAST-MODIFIED in the feed. Implementation: `captureSchedTimes()` stores pre-departure dep/arr in `schedule_sched_times_<sourceKey>` keyed by `legId()` = type|flight|from|to|checkin-date (NOT evKey — SUMMARY contains the reg, which changes on aircraft swaps); `seedSchedFromSnapshots()` back-fills once (`…_seeded` flag). `legTimes4Export(e)` → state scheduled/actual/pending (pending = landed < `ACTUALS_PENDING_MS` 72 h and feed == remembered schedule) + schedDep/schedArr/actDep/actArr/blockMs; used by `buildEntity`/`buildPlogRow`/`buildRbRow` and the card export button; `exportFlights()` confirm()s when pending legs are included. Old flights w/o record: STD from plan.std or checkin+`briefOffsetFor()`, STA blank. Test harness: Playwright with `page.clock.install` at 3 instants (pre-dep / landed-unchanged / landed-with-edited-ICS) — old e13c… scratchpad `pw/` has node_modules + libatk libs. Known gaps: RFT role gets no PIC/SIC time; PilotLog TIME_TOTAL (mandatory) blank for unflown legs.

- **Caching / offline (2026-09-05)**: iOS web-clip showed stale build because the page had NO Cache-Control → Safari heuristic freshness. Fix = vhost `<LocationMatch "^/roster/(index\.html|sw\.js)?$"> Header set Cache-Control "no-cache, must-revalidate"` (backup /root/00b-looping.org-ssl.bak-rostercache-20260905) + service worker `sw.template.js` → `sw.js` (gitignored, built by build.sh with md5 stamp). SW = network-first (4 s timeout) for `/roster/` + `data/flightplans.json`, cache-first for fonts.googleapis/gstatic + images.pexels.com, everything else pass-through. Verified with Playwright: online reload picks up a changed index.html immediately; with the server stopped the page + data + fonts come from cache. NOT a standalone PWA on purpose (no manifest / apple-mobile-web-app-capable): standalone web apps on iOS get their own localStorage, so users re-adding the shortcut would lose saved sources/history. Users already stuck on the old cached build must reload once in Safari (or delete/re-add the shortcut) — after that no-cache + SW keep them current.

- **Alexis ICS event formats** (learned 2026-07-18): FLT descriptions carry times/TFT/PEQ then a `Crew:` header before `*** ROLE ***` sections (the crew list is sent twice — the parser stops at the first repeated role). Sim/training events (`SIMU`, `ENTM3`, `OPSM3`) list crew directly as `*** ELV ***`/`*** INS ***` sections with **no `Crew:` header**. MEP legs come both with (`MEP - SB410 - NOU/AKL - FONEA`) and without (`MEP - AKL/NAN`) a flight number — `cardHTML` must route on `from`+`to`, not on the flight number. `REST - CITY` has an empty description and renders via `cardHOT`. `parseDesc` returns `extra` (unrecognized lines) which every card displays so information is never silently dropped.
