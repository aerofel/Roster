- **Alexis ICS event formats** (learned 2026-07-18): FLT descriptions carry times/TFT/PEQ then a `Crew:` header before `*** ROLE ***` sections (the crew list is sent twice — the parser stops at the first repeated role). Sim/training events (`SIMU`, `ENTM3`, `OPSM3`) list crew directly as `*** ELV ***`/`*** INS ***` sections with **no `Crew:` header**. MEP legs come both with (`MEP - SB410 - NOU/AKL - FONEA`) and without (`MEP - AKL/NAN`) a flight number — `cardHTML` must route on `from`+`to`, not on the flight number. `REST - CITY` has an empty description and renders via `cardHOT`. `parseDesc` returns `extra` (unrecognized lines) which every card displays so information is never silently dropped.
